# Arc Nigeria — Growth Map (DRAFT, pending approval)

Scope: growth, marketing and distribution for **Arc** (Circle's USDC-gas Layer 1) in Nigeria, with **Arc Studio** (the prompt-to-onchain-app AI agent) as the main builder on-ramp.

All numeric targets below are **placeholders to agree on**, not benchmarks.

---

## 1. What "growth" means here

**North Star (proposed):** *Weekly Active Nigerian Builds* — Nigerian-origin apps on Arc mainnet with ≥1 real USDC transaction in the week.

It ties together the three things that matter: builders (supply), shipped apps (activation), and USDC usage (value).

Supporting outcomes:

| Layer | Metric |
|---|---|
| Builders | Nigerian Arc Studio accounts → activated builders |
| Apps | Apps exported/deployed to Arc mainnet |
| Usage | USDC volume and unique wallets through Nigerian apps |
| Business | Fintechs/merchants integrating App Kits (payments, onramp, bridging) |
| Community | Active members, event attendees, ambassadors |

---

## 2. Arc Studio lifecycle (core funnel)

| # | Stage | Definition | Key metric | Nigeria levers |
|---|---|---|---|---|
| 0 | **Aware** | Heard of Arc / Studio | Reach, site visits from NG, UTM clicks | X/Twitter, Web3 Lagos-style communities, university clubs, dev YouTubers |
| 1 | **Signed up** | Created Studio account | Sign-ups (NG), visit→sign-up % | Event QR codes, ambassador referral links |
| 2 | **First prompt** | Described an app in Studio | % sign-ups prompting within 24h | Nigeria-specific prompt templates (remittance, ajo/esusu savings, invoicing, school fees) |
| 3 | **First app generated** | Studio produced a working app | Time-to-first-app | Low-bandwidth tips, live build nights |
| 4 | **Tested on testnet** | Ran app on Arc testnet | Testnet deploys, faucet usage | Office hours, WhatsApp/Telegram help desk |
| 5 | **Exported / owned** | Code exported to own repo | Export rate | GitHub workshops, "ship it" challenges |
| 6 | **Mainnet live** | Deployed on Arc mainnet | Mainnet deploys (NG) | Deployment grants, showcase demo days |
| 7 | **Transacting** | Real users moving USDC | Weekly active apps, USDC volume, unique wallets | Onramp partners, merchant pilots, co-marketing |
| 8 | **Retained / Advocate** | Builds again, refers, mentors | 30/90-day builder retention, referrals, ambassadors | Ambassador program, grants tier 2, featuring on Arc channels |

**Drop-off watch points:** 1→2 (blank-page problem), 4→6 (testnet-to-mainnet gap), 6→7 (no users / no onramp).

---

## 3. Segments

1. **Student & early-career devs** — universities (UNILAG, OAU, UI, UNN, Covenant, FUTA). Volume, top of funnel.
2. **Indie/pro Web3 devs** — already shipping on EVM; fastest to mainnet.
3. **Non-technical founders** — Studio's prompt-to-app is the hook.
4. **Fintechs & businesses** — App Kits for payments, payouts, FX, remittance; drives USDC volume.
5. **End users** — reached via the apps and partners above, not directly.

## 4. Distribution channels

| Channel | Role | Stage it moves |
|---|---|---|
| **Arc Studio build nights** (Lagos, Abuja, Port Harcourt, Enugu, Ibadan) | Hands-on first app in one evening | 1→5 |
| University chapters / campus ambassadors | Volume sign-ups | 0→2 |
| Tech hubs & communities (co-hosting) | Credibility, venues | 0→3 |
| Hackathons with mainnet-deploy requirement | Push past testnet | 4→6 |
| Fintech / merchant partnerships | Real USDC flows | 6→7 |
| X/Twitter, YouTube, WhatsApp/Telegram groups | Awareness + support | 0, 4 |
| Builder grants & showcase demo days | Mainnet + retention | 6→8 |
| Ambassador / referral program | Compounding reach | 8→0 |

Compliance note: positioning stays on builders/payments infrastructure; partner and consumer campaigns get checked against current SEC Nigeria and CBN rules before launch.
