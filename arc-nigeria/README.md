# Arc Nigeria Growth dashboard

Source for the team dashboard published at https://claude.ai/artifact/Qpw6uYVJeR5PpTP2yQpaSR.
The strategy behind it is in `docs/arc-nigeria-growth-map.md`.

- `index.html` is the whole page (no build step). Team records, monthly numbers and settings are kept in the artifact's shared database, not in this file.
- To change the page, edit `index.html` and republish it to the same artifact URL.
- Records marked "Example" are illustrative. Remove them in Settings once real data is in.
